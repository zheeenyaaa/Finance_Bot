# FinanceBot

FinanceBot — Telegram-бот для личного учета доходов и расходов. Данные
хранятся локально в SQLite, поэтому для обычного запуска не нужен отдельный
сервер базы данных.

## Возможности

- Несколько счетов с отдельными остатками.
- Создание, переименование, изменение суммы и удаление счетов.
- Категории доходов и расходов: создание, переименование и удаление.
- Быстрое добавление транзакций обычным сообщением.
- Доходы, расходы и сальдо за выбранный месяц.
- Статистика за сегодня, последнюю неделю и за все время.
- Последние операции и группировка статистики по категориям.
- Напоминания о внесении расходов в выбранное время.
- Настройка часового пояса пользователя.
- Удаление всех данных пользователя с подтверждением.
- Отправка обратной связи владельцу бота.
- Административные команды и статистика пользователей.

При первом `/start` бот создает пользователю счет по умолчанию и стандартные
категории: еда, транспорт, жилье, красота, здоровье, быт и зарплата.

## Требования

- Python 3.11.
- Аккаунт Telegram.
- Токен бота, созданного через `@BotFather`.
- Git — только если проект будет клонироваться из репозитория.

SQLite входит в стандартную библиотеку Python и является единственной
поддерживаемой базой данных проекта.

## Установка на Windows

Откройте PowerShell в папке, куда хотите поместить проект:

```powershell
git clone <АДРЕС_РЕПОЗИТОРИЯ>
cd finance
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
Copy-Item configs\settings.example.py configs\settings.py
```

Если PowerShell запрещает активацию окружения, разрешите ее только для текущего
окна и повторите команду активации:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
```

## Установка на macOS или Linux

```bash
git clone <АДРЕС_РЕПОЗИТОРИЯ>
cd finance
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
cp .env.example .env
cp configs/settings.example.py configs/settings.py
```

Если команда `python3.11` отсутствует, сначала установите Python 3.11 средствами
вашей операционной системы.

## Настройка

Откройте созданный файл `.env` и замените значения:

```dotenv
TOKEN=PASTE_TELEGRAM_BOT_TOKEN_HERE
ADMIN_USER_ID=ваш_числовой_Telegram_ID
DB_FILE=finance_bot.db
```

Параметры:

| Переменная | Назначение |
| --- | --- |
| `TOKEN` | Секретный токен Telegram-бота |
| `ADMIN_USER_ID` | Telegram ID первого администратора |
| `DB_FILE` | Путь к локальной базе SQLite |

Не добавляйте кавычки вокруг значений и не отправляйте `.env` другим людям.
Файлы `.env` и `configs/settings.py` намеренно исключены из Git.

Проверить доступность SQLite можно командой:

```bash
python -m utils.test_db
```

При первом полноценном запуске таблицы будут созданы автоматически.

## Запуск

Обычный запуск:

```bash
python main.py
```

После сообщения `Бот запущен...` откройте своего бота в Telegram и отправьте
команду `/start`. Для остановки нажмите `Ctrl+C` в терминале.

Для разработки доступен режим автоматического перезапуска при изменении
Python-файлов:

```bash
python bot_runner.py
```

Не запускайте `main.py` одновременно в нескольких терминалах: Telegram разрешает
только один активный polling-процесс для одного токена, а несколько процессов
могут одновременно обращаться к SQLite.

## Использование

Основное управление доступно через кнопки меню после `/start`.

### Добавление транзакции

Операция на счете по умолчанию:

```text
100 еда обед
50000 зарплата аванс
```

Операция на конкретном счете:

```text
350 карта транспорт такси
```

Форматы:

```text
сумма категория [комментарий]
сумма счет категория [комментарий]
```

Категория должна уже существовать. При указании счета непосредственно в
сообщении его название должно состоять из одного слова.

### Пользовательские команды

| Команда | Назначение |
| --- | --- |
| `/start` | Регистрация пользователя и главное меню |
| `/menu` | Открыть главное меню |
| `/help` | Справка по добавлению операций |
| `/accounts` | Управление счетами |
| `/accounts_list` | Список счетов |
| `/categories` | Управление категориями |
| `/categories_income` | Категории доходов |
| `/categories_expense` | Категории расходов |
| `/balance` | Баланс по месяцам |
| `/statistics` | Меню статистики |
| `/expenses_by_this_day` | Операции и итоги за сегодня |
| `/settings` | Напоминания и часовой пояс |
| `/feedback` | Отправить сообщение администратору |
| `/cancel` | Отменить ввод обратной связи |
| `/delete_all_information` | Удалить все свои данные |

### Административные команды

Первый администратор берется из `ADMIN_USER_ID` при запуске.

| Команда | Назначение |
| --- | --- |
| `/admin` | Проверить статус администратора |
| `/stats` | Количество всех и новых пользователей |
| `/addadmin ID [username]` | Добавить администратора |
| `/adminhelp` | Показать административную справку |

## Данные и резервные копии

По умолчанию данные находятся в `finance_bot.db` в корне проекта. Файл содержит
Telegram ID пользователей и их финансовые записи, поэтому его нельзя публиковать
или передавать посторонним.

Для простой резервной копии:

1. Остановите бота.
2. Скопируйте `finance_bot.db` в защищенное место.
3. Запустите бота снова.

Файлы SQLite, включая служебные `-wal`, `-shm` и `-journal`, исключены из Git.

## Логи

При текущей конфигурации логирование отключено в `bot_logging.py`. Бот не создает
и не дописывает `logs/bot.log`; важные сообщения запуска остаются в терминале
через обычный `print`.

## Безопасность перед публикацией

- Никогда не коммитьте `.env`, `configs/settings.py`, базу SQLite или логи.
- Перед коммитом проверяйте `git status --short --ignored`.
- Убедитесь, что приватные файлы игнорируются:

  ```bash
  git check-ignore -v .env configs/settings.py finance_bot.db
  ```

- Не вставляйте токены и пароли непосредственно в Python-код.
- Если секрет когда-либо попал в коммит, простого удаления файла недостаточно:
  немедленно замените секрет и при необходимости очистите историю Git.
- При утечке Telegram-токена перевыпустите его через `@BotFather`.

## Частые проблемы

- `No module named 'dotenv'`: активируйте `.venv` и повторите
  `pip install -r requirements.txt`.
- Ошибка о `TOKEN`: проверьте, что `.env` находится в корне проекта и содержит
  настоящий токен без кавычек.
- Ошибка Telegram `409 Conflict`: остановите другую копию бота.
- `database is locked`: убедитесь, что с базой не работают несколько экземпляров
  приложения.
